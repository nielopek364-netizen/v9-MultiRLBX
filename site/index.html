v9 MultiRLBX

Nowoczesny, wielokontowy launcher i menedżer wydajności dla Robloxa na Windows. Bez zbędnych dodatków: szybki interfejs desktopowy, Smart Eco, układanie okien, własny system makr .v9m i pełne szyfrowanie lokalne.

Kompilacja (Build.bat) System Makr .v9m GitHub · v9pv

Architektura v1.0.0

Nowoczesny UI (Non-WinForms)

Chromeless powłoka desktopowa + tray host z wbudowanym przełącznikiem PL / EN, trybem Dark/Light oraz 5 kolorami akcentów.

Smart Eco & RAM Cleaner

Wątkowo bezpieczny silnik Max Alts z cache'owaniem stanu PID, rezerwacją rdzeni CPU i progiem przycinania pamięci roboczej.

Siatka okien & Presety

Automatyczne kafelkowanie wielu klientów Roblox na wybranych monitorach, autorski układ okien i presety FFlags.

Custom Makra (.v9m)

Autorski format #v9m 2: nagrywanie hookami bezpośrednio w panelu HTML, kroki Wait/Key/Click, jitter humanizacji i fokus konta.

Watchdog & Crash Breaker

Automatyczny restart po crashu z ochroną przed pętlą awarii, wykrywaniem zawieszonych okien (Ghost Killer) i Anti-AFK.

Bezpieczeństwo lokalne

Cookies chronione DPAPI lub AES-256 + HMAC. Panel UI działa wyłącznie na localhost (127.0.0.1) z tokenem sesji i zero telemetrii.

Szybki start

1. Pobierz z GitHuba

Sklonuj repozytorium z profilu github.com/nielopek364-netizen lub rozpakuj paczkę ZIP.

2. Kompilacja 1-klikiem

Uruchom Run.bat, a Windows automatycznie skompiluje aplikację używając .NET Framework 4 i otworzy panel.

3. Dodaj konta i makra

Zaimportuj konta w zakładce Konta i utwórz własne sekwencje .v9m w Studio Makr.
